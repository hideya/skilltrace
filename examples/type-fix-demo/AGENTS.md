# TypeScript Repairs

This repository contains a small TypeScript project.

## Commands

- `npm run tsc` - Run the type check

## Repair Workflow

When asked to fix TypeScript, syntax, or source errors:

1. Read `.agents/skills/type-fix/SKILL.md`.
2. Make the smallest code changes needed to pass `npm run tsc`.
3. Do not modify files outside this repository.

Use the existing source files as the task input.
